# Demo artwork

Original local SVG illustrations for VRUM demo accounts. Each account has a stable, distinct character; no external avatar service or real person's photograph is used.

To upgrade existing demo data without resetting posts, passwords, votes or custom pictures, run `npm run seed:avatars` from `backend`. Fresh `seed:demo` and `seed:tech` runs also apply these pictures. Only known demo identities and ownerless seed communities with missing/legacy pictures are updated.
